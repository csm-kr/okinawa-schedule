# 화면 전환 맵

> **Refs**: [SCREENS](./SCREENS.md) · [USER_FLOW](../user/USER_FLOW.md)

화면 간 전환과 조건부 UI 상태를 정의한다. 사용자 관점 단계는
[USER_FLOW](../user/USER_FLOW.md), 화면 상세는 [SCREENS](./SCREENS.md).

## 전환 맵
```
링크/홈화면
   │
   ├─▶ 공개 타임라인 `/`
   │        ├─ 날짜 탭 ──▶ (같은 화면) 해당 날짜 타임라인
   │        └─ 상태 카드 탭 ──▶ (같은 화면) 현재 항목으로 스크롤
   │
   └─▶ `/admin`
            ├─ (미인증) 로그인 화면 ──비밀번호 맞음──▶ 편집 화면
            │                        └─비밀번호 틀림─▶ (제자리) 에러
            └─ (편집) [저장] ──version 일치──▶ 공개 `/` 갱신
                              └─version 불일치─▶ (제자리) 409 안내
```

## 화면별 진입/이탈
| 화면 | 진입 경로 | 이탈 경로 |
|---|---|---|
| 공개 타임라인 `/` | 카톡 링크·홈화면 | (앱 종료) / `/admin` 직접 입력 |
| 로그인 `/admin` | `/admin` 미인증 진입 | 성공 시 편집 화면 |
| 편집 `/admin` | 로그인 성공 | 로그아웃 → 로그인 / 저장 후 잔류 |

## 조건부 UI 상태
| 화면 | 조건 | 표시 |
|---|---|---|
| 공개 `/` | 행사 기간 전 | 상태 카드 "행사 시작 전이에요" |
| 공개 `/` | 행사 기간 후 | 상태 카드 "모든 일정이 끝났어요…" |
| 공개 `/` | 일정 0건 | 빈 상태 "아직 등록된 일정이 없어요" |
| 공개 `/` | 로딩 중 | 타임라인 스켈레톤 |
| 공개 `/` | 데이터 에러 | "일정을 불러오지 못했어요" + 재시도(가능 시 캐시) |
| `/admin` | 미인증 | 로그인 화면 |
| `/admin` | 저장 충돌 | 409 안내 배너 |
