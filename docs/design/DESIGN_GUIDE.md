# 디자인 가이드

> **Refs**: [SCREENS](./SCREENS.md) · [SCREEN_FLOW](./SCREEN_FLOW.md) · [USER_FLOW](../user/USER_FLOW.md)

토큰·컴포넌트·금지 사항을 정의한다. 화면별 구성은 [SCREENS](./SCREENS.md), 전환은
[SCREEN_FLOW](./SCREEN_FLOW.md).

## 디자인 원칙
1. **큰 글씨·높은 대비 우선** — 어르신이 멀리서도 읽힌다. "작고 예쁜"보다 "잘 읽힌다".
2. **"지금 뭐?"에 1초 안에 답** — 진입 시 스크롤 없이 현재 상태가 먼저 보인다.
3. **절제** — 정보(시간·제목·장소)가 주인공. 색(살구)은 "지금"을 가리키는 데만 쓴다.
4. **한 손·세로 스크롤** — 주요 동작(날짜 전환)은 화면 위쪽 큰 탭.

## AI 슬롭 안티패턴 — 하지 마라
| 금지 사항 | 이유 |
|-----------|------|
| backdrop-filter: blur() | glass morphism은 AI 템플릿의 흔한 징후 |
| gradient-text | AI SaaS 랜딩의 1번 특징 |
| "Powered by AI" 배지 | 장식, 가치 없음 |
| box-shadow 글로우 애니메이션 | 네온 글로우 = AI 슬롭 |
| 보라/인디고 브랜드 색 | "AI = 보라색" 클리셰 (우린 크림+살구) |
| 모든 카드 동일 rounded-2xl | 균일 둥근 모서리는 템플릿 느낌 |
| 배경 gradient orb | 모든 AI 랜딩의 장식 |

## 토큰

### 색상 — 배경/표면
| 용도 | 값 |
|------|------|
| 페이지(크림) | #FFF9F3 |
| 카드/입력 표면 | #FFFFFF |
| 경계선 | #EFE4DA |

### 색상 — 텍스트
| 용도 | 값 |
|------|------|
| 본문·제목(잉크) | #3D3430 |
| 보조·past 일정 | #8A7F76 |
| 살구 위 글자 | #FFFFFF |

### 색상 — 포인트/시맨틱
| 용도 | 값 |
|------|------|
| 포인트(살구) — "지금" 바·점·뱃지 배경 | #E07A5F |
| 살구-strong — 살구가 글자/버튼 라벨일 때(대비 보강) | #C75B43 |

> 접근성: 살구 #E07A5F는 크림 위 대비가 약하다(≈2.5:1). **면에만** 쓰고, 글자/버튼 라벨은
> #C75B43(≈4.5:1, AA). 본문은 항상 잉크(#3D3430).

### 타이포그래피 (큰 글씨가 기본, rem 기반)
| 용도 | 크기 | 두께 |
|------|------|------|
| 현재 상태 카드 제목 | 26px | 700 |
| 화면 헤더(행사명) | 24px | 700 |
| 시간 숫자(tabular-nums) | 22px | 700 |
| 일정 제목 | 21px | 600 |
| 본문/장소 | 18px(하한) | 400–500 |
| 보조/메모 | 16px(절대 하한) | 400 |

line-height 1.5–1.6. 폰트: Pretendard 또는 시스템 한글 스택.

### 간격·레이아웃
- 모바일 우선 단일 컬럼, 좌측 정렬 기본.
- 충분한 여백으로 항목 구분(구분선 `line` 보조).

## 컴포넌트
### 현재 상태 카드
```
흰 표면(#FFFFFF) + 좌측 살구 바(#E07A5F) + 큰 제목(26/700). "지금 진행 중" 뱃지(살구 면+흰 글자).
```
### 타임라인 항목
```
past: 텍스트 #8A7F76, 점 비움(○)
current: 좌측 살구 바 + 굵게 + 한 단계 큰 글씨 + "지금" 뱃지 + 채운 점(●)
upcoming: 잉크 기본 + 점 테두리(◌)
```
### 버튼
```
Primary: 높이 56px, 글자 18–20/600, bg #C75B43 + 흰 글자, 하단 고정
Secondary: 높이 ≥48px, ink 테두리 + 크림 배경
Danger(삭제): 색·위치로 분리
```
### 입력 필드
```
높이 ≥48px, 글자 18px, 흰 표면 + #EFE4DA 테두리, 시각은 <input type="time">
```

## 애니메이션
- 허용: fade-in / slide-up (150–200ms), 상태 카드 등장·탭 전환에만.
- 그 외 모든 애니메이션 금지(특히 글로우·바운스).

## 아이콘
- SVG 인라인, strokeWidth 1.75 내외(큰 글씨 톤에 맞춰 약간 굵게).
- 둥근 배경 박스로 아이콘을 감싸지 않는다.
