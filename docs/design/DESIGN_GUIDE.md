토큰·컴포넌트·금지 사항을 정의한다. 화면별 구성은 [SCREENS](./SCREENS.md).

> **2026-06-18 리디자인** — 사용자 지시로 초기 "절제된 크림+살구 라이트"에서 **볼드 모던**(글래스모피즘·그라데이션·은은한 글로우/모션)으로 전환했다. 색은 (인디고·아이보리 시안을 잠시 시험한 뒤) **브랜드인 크림+살구/코랄을 유지·모던화**하는 것으로 정리됐다 — "Cream & Apricot Modern". 근거·결정은 [ADR-008/009](../agent/ADR.md). **정확·최신 토큰 값의 정본은 [`tailwind.config.ts`](../../tailwind.config.ts) · [`globals.css`](../../src/app/globals.css)** 이며, 아래는 방향 요약이다(색 미세조정은 흔하므로 값은 코드를 따른다).

## 디자인 원칙
1. **큰 글씨·높은 대비 우선** — 어르신이 멀리서도 읽힌다. 모던하게 가도 본문 18px·터치 48px·대비는 지킨다.
2. **"지금 뭐?"에 1초 안에 답** — 진입 시 스크롤 없이 현재 상태 카드가 먼저. 현재 항목은 코랄 글로우 링 + "지금 ✨" + 반짝(시머) 시간으로 "여기가 지금"을 분명히.
3. **프리미엄·모던 무드, 단 정보가 주인공** — 글래스·그라데이션·글로우·모션은 분위기를 위해 쓰되 시간·제목·장소의 가독성을 해치지 않는다(일관·절제).
4. **한 손·세로 스크롤** — 주요 동작(날짜 전환)은 화면 위쪽 큰 탭. 모바일은 핀치 확대/축소를 막고
   **상하 스크롤만** 허용한다(viewport `userScalable:false` + `touch-action: pan-y`; 지도 내부는 예외). [ADR-011]

## 스타일 가이드 — 의도적으로 쓰는 것 / 그래도 피할 것
초기 가이드는 아래 기법들을 "AI 슬롭"으로 금지했으나, 사용자가 볼드 모던을 택해 **이제 의도적으로 사용**한다(슬롭이 되지 않도록 일관되게).

| 이제 의도적으로 사용(코히어런트하게) | 여전히 피한다(진짜 슬롭) |
|---|---|
| backdrop-filter blur 라이트 글래스 카드 | 가독성 해치는 저대비·작은 글씨 |
| 그라데이션 텍스트(타이틀·강조 숫자) | 의미 없는 장식 과다·일관성 없는 색 남발 |
| 은은한 글로우/펄스(현재 상태 한정) | 모션 남용·`prefers-reduced-motion` 무시 |
| 살구/코랄·앰버 강조 + 크림 베이스 + 살구 글로우 오브 | "Powered by AI" 류 배지·무가치 장식 |

- **모든 모션은 `prefers-reduced-motion: reduce`에서 정지/정적화**(접근성). 시머 텍스트는 정적 그라데이션으로 가독성 유지.
- 인디고/보라 브랜드 색은 쓰지 않는다(브랜드는 크림+살구). 인디고/아이보리 시안은 시험 후 폐기.

## 컴포넌트
- **현재 상태 카드**: 라이트 글래스 + 코랄 글로우. "지금 진행 중" 뱃지(살구 면) + 다음 항목 미리보기.
- **타임라인 항목**: past=흐리게·빈 점 / current=코랄 글로우 링 + "지금 ✨" 뱃지 + 펄스 점 + **반짝(시머) 시간** / upcoming=살구 테두리 점. 제목·장소·메모는 한국어 단어 단위 줄바꿈(`word-break:keep-all`).
- **지도 번호 뱃지**: 좌표 있는 항목은 제목 앞에 **살구/앰버 번호 원**(지도 마커와 동일 디자인·동일 번호=`routeNumberById`). "이 번호를 아래 지도에서 찾으세요". 좌표 없는 항목엔 번호 없음.
- **현재 시간대 블록**: 지금 ±60분 안에 시작하는 항목(+진행 중 항목)을 **따뜻한 코랄 음영 띠**로 묶어 강조(`isInNowBlock`). 연속 구간은 바깥 모서리만 둥근 하나의 박스.
- **날짜별 동선 지도**: 라이트 타일 + 시간순 살구/앰버 번호 마커 + 코랄 경로선 + **🚗 자동차 이동 마커**(rAF). **url 있는 마커는 코랄 링 + 누르면 새 탭으로 링크**.
- **버튼/입력(어드민)**: 높이 56/≥48px, 글자 18px+. 항목마다 **"📍 링크에서 좌표 채우기"**(구글맵 링크→위도·경도 자동 입력, 단축링크는 서버가 펼침). [ADR-010]
