# 화면 카탈로그

> **Refs**: [DESIGN_GUIDE](./DESIGN_GUIDE.md) · [SCREEN_FLOW](./SCREEN_FLOW.md)

화면별 구성과 카피를 정의한다. 전환 맵은 [SCREEN_FLOW](./SCREEN_FLOW.md), 토큰은
[DESIGN_GUIDE](./DESIGN_GUIDE.md).

## 화면 1: 공개 타임라인
| 항목 | 내용 |
|---|---|
| 경로 | `/` |
| 목적 | 가족이 현재 시각 기준 "지금/다음" 일정을 한눈에 확인 |
| 진입 | 카톡 링크 / 홈화면 아이콘 |
| 구성 요소 | 헤더(행사명·날짜범위) · 현재 상태 카드 · 날짜 탭 · 타임라인 리스트(좌표 항목엔 지도와 같은 번호 뱃지 · 현재 시간대 항목은 음영 띠 · 항목 🔗) · 날짜별 동선 지도(좌표 있는 날만, 번호 마커) |
| 주요 액션 | 날짜 탭 전환 · 상태 카드 탭(현재 항목으로 스크롤) · 항목 🔗 탭(새 탭으로 지도 열기) |
| 상태 | 기본 / 로딩(스켈레톤) / 빈(일정 없음) / 에러(재시도) / 기간 전·후 |

### 카피
| 위치 | 텍스트 |
|---|---|
| 헤더 제목 | "조인수 · 김인숙 부부 칠순잔치" |
| 상태 카드(진행 중) | "지금 진행 중" |
| 상태 카드(다음) | "다음 ▸ {제목} {시각}" |
| 상태 카드(기간 전) | "행사 시작 전이에요" |
| 상태 카드(기간 후) | "모든 일정이 끝났어요. 함께해 주셔서 고맙습니다" |
| 빈 상태 | "아직 등록된 일정이 없어요" |
| 에러 | "일정을 불러오지 못했어요" / 버튼 "다시 시도" |

## 화면 2: 관리자 로그인
| 항목 | 내용 |
|---|---|
| 경로 | `/admin` (미인증 시) |
| 목적 | 공용 비밀번호로 편집 권한 획득 |
| 구성 요소 | 비밀번호 입력 · "들어가기" 버튼(56px) |
| 주요 액션 | 비밀번호 입력 → 들어가기 → 편집 화면 |
| 상태 | 기본 / 에러(틀림, 입력칸 흔들림) |

### 카피
| 위치 | 텍스트 |
|---|---|
| 라벨 | "가족 비밀번호" |
| 버튼 | "들어가기" |
| 에러 | "비밀번호가 달라요" |

## 화면 3: 관리자 편집
| 항목 | 내용 |
|---|---|
| 경로 | `/admin` (인증 후) |
| 목적 | 일정 추가·수정·삭제 후 저장 |
| 구성 요소 | 행사 제목 입력(맨 위 title) · 날짜 탭 · 항목 편집 카드(시각/제목/장소/메모/위도/경도/링크) · [📍 링크에서 좌표 채우기] · [+ 일정 추가] · [저장](하단 고정) · [로그아웃] |
| 주요 액션 | 항목 편집 → 저장(PUT) → 공개 반영 |
| 상태 | 기본 / 저장 중 / 저장 성공(토스트) / 409 충돌 / 네트워크 에러 |

### 카피
| 위치 | 텍스트 |
|---|---|
| 추가 버튼 | "+ 일정 추가" |
| 좌표 채우기 | "📍 링크에서 좌표 채우기" / 진행 "좌표 찾는 중…" / 실패 "링크에서 좌표를 못 찾았어요. 링크를 확인해 주세요" |
| 저장 버튼 | "저장" |
| 저장 성공 | "저장됐어요" |
| 충돌(409) | "다른 곳에서 일정이 바뀌었어요. 새로고침 후 다시 저장해 주세요" |
| 삭제 확인 | "이 일정을 삭제할까요?" |
