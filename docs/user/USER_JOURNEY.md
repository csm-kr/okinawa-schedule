# User Journey

> **Refs**: [PRD](./PRD.md) · [USER_FLOW](./USER_FLOW.md)

페르소나별로 시간 축에 따른 서사를 기술한다. "클릭 단위 단계"는 [USER_FLOW](./USER_FLOW.md),
여기서는 **언제·왜·어떤 맥락에서** 제품을 쓰는지를 서술한다.

## 페르소나
| 페르소나 | 역할 | 핵심 니즈 |
|---|---|---|
| 어르신 가족(주인공 본인·친척) | 폰으로 일정 확인 | 큰 글씨로 "지금 어디 모이는지"를 헷갈림 없이 |
| 자녀·조카 | 폰으로 일정 확인 + 어르신 안내 | 다음 일정·장소를 빠르게 보고 가족을 챙김 |
| 편집자(주최 자녀) | 일정 작성·수정 | 행사 전후로 폰에서 빠르게 일정 갱신, 전원에게 즉시 반영 |

## 시간 축 서사

### 편집자 — 행사 준비 사이클
| 시점 | 행동 | 감정/동기 | 닿는 기능 |
|---|---|---|---|
| D-7 | `/admin`에서 날짜·일정 초안 입력 | "한 번 정리해두면 카톡으로 같은 질문 안 받겠지" | admin 편집 |
| D-1 | 식당 시간·장소 확정 반영 | "내일 헷갈리지 않게" | admin 편집 → 저장 즉시 반영 |
| D-day | 현장에서 변경(지연·장소 이동) 즉시 수정 | "지금 바로 가족들이 봐야 해" | 모바일 admin 수정 + revalidate |

### 어르신 가족 — 행사 당일
| 시점 | 행동 | 감정/동기 | 닿는 기능 |
|---|---|---|---|
| 아침 | 홈화면 아이콘으로 앱 열기 | "오늘 일정이 뭐였더라" | PWA · 현재 상태 카드 |
| 일정 사이 | "다음 어디로 가지?" 확인 | "늦지 않게" | "다음 ▸" 미리보기 |
| 행사 중 | 지금 진행 중 항목 강조 확인 | 안심 | 라이브 강조 |

### 자녀·조카 — 행사 당일
| 시점 | 행동 | 감정/동기 | 닿는 기능 |
|---|---|---|---|
| 이동 시 | 날짜 탭으로 전체 흐름 훑기 | "오늘 동선 파악" | 날짜 탭 · 타임라인 |
| 어르신 안내 | "지금 ○○ 시간이에요" 알려줌 | 가족 챙김 | 현재 상태 카드 |

## 핵심 순간 (Moments that matter)
- 앱을 열자마자 스크롤 없이 "지금 진행 중"이 큰 글씨로 보이는 순간 — 제품 가치가 결정된다.
- 편집자가 현장에서 일정을 고치자 가족 화면이 곧 갱신되는 순간 — 카톡 재공지가 사라진다.
- 어르신이 도움 없이 글자를 읽고 다음 장소를 확인하는 순간 — 가독성 설계가 보상받는다.
