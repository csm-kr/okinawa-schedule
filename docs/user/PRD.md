# PRD: 조인수·김인숙 여사님 환갑잔치 가족 안내 웹앱

> **Refs**: [USER_JOURNEY](./USER_JOURNEY.md) · [USER_FLOW](./USER_FLOW.md) · [DESIGN_GUIDE](../design/DESIGN_GUIDE.md) · [ADR](../agent/ADR.md)

## 제품 정의
조인수·김인숙 여사님 환갑잔치 겸 가족 여행(2박 3일 이상)의 일정을, 가족이 **링크 하나로
즉시** 확인하는 모바일 웹앱. 회원가입 없음, 안드로이드·iOS 동일, PWA(홈화면 추가).

## 목표
"지금 몇 시에 어디서 뭘 하는지"를, 카톡에 흩어진 메시지를 뒤지지 않고 한 화면에서 **현재
시각 기준으로 자동으로** 짚어준다.

## 사용자
가족 구성원(다세대). 환갑잔치이므로 **60대 이상 어르신 시청자 비중이 크다**. 대부분 보기
전용이고, 일정을 고치는 **편집자는 1명**(주최 자녀). 상세 서사는 [USER_JOURNEY](./USER_JOURNEY.md).

## 핵심 기능
1. **날짜별 라이브 타임라인** — 2박3일+ 날짜 탭. 현재 시각(Asia/Seoul) 기준 "지금 진행 중 /
   다음" 자동 강조. 클라이언트가 30–60초마다 재계산.
2. **현재 상태 카드** — 진입 즉시(스크롤 없이) 지금/다음(또는 기간 전·후)을 큰 글씨로 표시.
3. **공용 비밀번호 `/admin`** — 재배포 없이 일정 추가·수정·삭제(모바일 편집). 저장 즉시 공개 반영.
4. **PWA** — 홈화면 추가, 카톡 링크 공유. iOS·안드로이드 동일.

## 비목표 (MVP 제외)
- 지도/길찾기 · 참석자 명단·RSVP · 사진 갤러리 · 축하글 방명록
- 카운트다운 · 다국어 · 알림/푸시 · 계정/회원가입

## 디자인 방향
- **다정한 파스텔 + 큰 글씨**(어르신 가독성 최우선). 크림 베이스 + 살구 포인트 1색.
- 본문 ≥18px, 시간/제목은 더 크게, 버튼 ≥48px(주요 56px), 대비 AA.
- 상세 토큰·컴포넌트는 [DESIGN_GUIDE](../design/DESIGN_GUIDE.md) 참조.

## 성공 기준 (요약)
- 진입 후 1초 안에 "지금 뭐 하는지"가 보인다.
- 편집자가 폰에서 일정을 고치면 가족 화면에 곧바로 반영된다.
- 어르신이 도움 없이 글자를 읽고 버튼을 누를 수 있다.
